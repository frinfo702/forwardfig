Write the figure, not the drawing.

Describe the model the way you would write it in PyTorch: layers are callables, modules have a forward, and a figure draws whatever they produce. Edges stay straight, the shapes are the ones papers use, labels take TeX, and frozen or trainable weights render as ice or magma. One file, no dependencies.

Install

npm install forwardfig

Figures from the papers

    Components

    Every block you can call, with the line that makes it. Layers take (label?, options?); the presets come with a label and color you can override.

    Textures

    Set texture on any block, or on a module for its group box. freeze() and trainable() give ice and magma and add the badge; the other textures leave the badge to them. crossed: true strikes out a block, or an edge with x.edge({ crossed: true }).

      Use it in a page

      Write blocks as modules next to your model code, then compose them in a figure. fig.mount() draws into the page; fig.svg() returns a string and also works in Node. Under the hood, fig.diagram() is plain data that draw() lays out, if you want to generate figures some other way.

      import { Figure, Module, mha, norm, ffn } from 'forwardfig'

class EncoderLayer extends Module {
  attn = mha()
  n1 = norm()
  ff = ffn()
  n2 = norm()
  forward(x) {
    const h = this.n1(this.attn(x), x)
    return this.n2(this.ff(h), h)
  }
}

const fig = new Figure({ flow: 'BT' })
new EncoderLayer({ repeat: 'N×' }).freeze()(fig.input('$x$'))
fig.mount('#figure')
