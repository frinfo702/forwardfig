Write the figure, not the drawing.

A small text format for ML architecture diagrams. Edges stay straight and orthogonal, the shapes are the ones papers use, labels take TeX, and frozen or trainable weights render as ice or magma. One file, no dependencies.

🧊 frozen🔥 trainable

Figures from the papers

    Use it in a page

    Put the source in any element with the class machine-mermaid and call run(). Or call render() to get an SVG string, which also works in Node.

    <pre class="machine-mermaid">
flow BT
q text "$Q$"
k text "$K$"
q, k -> mm -> sm
mm matmul
sm softmax
</pre>
<script type="module">
  import mm from './machine-mermaid.js'
  mm.run()
  // const svg = mm.render(source, { theme: 'dark' })
</script>
